# 配套训练键盘：设计目标

2026-10-16 · my-designer 主导 · Native SwiftUI / DesignKit · 演示数据。

## 范围与数量

动作选择与训练页原有 **各 9 种组合**。本轮键盘再提供 **3 种风格 × 3 种布局 = 9 种组合**；每种组合分别呈现重量、次数及 light/dark，共 36 张核心屏幕图。另有休息/撤销/无效输入六张、375pt 大字回退六张，总计 48 张键盘屏幕图与 18 张双输入对比板。

仍在隔离 Prototype layer，只依赖 DesignKit；不接入 SwiftData、UIKit inputView、真实训练、Watch 或 HealthKit。原有页面的布局和键盘布局是两条独立轴：导图采用 K1/L1、K2/L2、K3/L3 的代表搭配，工作室可自由搭配。没有将所有跨轴排列称作已验收版本。

## 三种风格与三种布局

风格继承已有 S1 Tide / S2 Graphite / S3 Ember 的 Theme，语义色独立。Tide 12pt 键帽与安静表面；Graphite 8pt 键帽、清晰描边和黑白 CTA；Ember 18pt 键帽与暖色强调。数字使用系统圆体与等宽布局。

| 布局 | 键盘结构 | 主要用途 / 取舍 |
|---|---|---|
| K1 全宽数字 | 两字段切换 + 全宽 3×4 数字区 + 下一项/保存输入 | 大键面、学习成本低，快捷能力在工具入口 |
| K2 拇指侧栏 | 数字区靠惯用手 + ±2.5kg/±1、上次、复制侧栏 + 左右手镜像 | 一手编辑和小调整；数字键比 K1 窄，但不低于触控目标 |
| K3 连续记组 | 8/10/12 次预设 + 复制 + 数字区 + 保存并记组 | 高频记录和连续训练；高度稍大，主操作会记组并开始休息，必须明确标注 |

所有数字保持 1–9 / 小数点 / 0 / 删除的相同空间顺序。K2 的镜像只移动侧栏，不翻转数字顺序。

## 行为与安全约定

- 打开即全选现有值；首个数字替换，后续追加。删除可清空全选值。重量允许两位小数，次数小数键禁用。
- 两字段共享本组草稿；切换不丢输入，取消丢弃本组草稿。键盘收起按钮保存两个字段，不记组；K1/K2 主操作为重量 → 次数 → 保存；K3 明确为“保存并记组”。
- 不把输入无效悄悄钳成别的值：空值、非有限数、重量超出 0–999kg、次数非 1–999 整数均禁用提交并显示说明。
- 草稿绑定打开时的动作 ID + 组 ID，不因切换活动动作写错行；重复提交不连带完成下一组。
- “上次”显式填入固定演示值；“复制到下一组”显式覆盖下一组输入，末尾才追加，不自动完成下一组。此操作先于草稿保存生效，取消草稿不会撤销已执行的复制。
- 工具入口显示文字且首项放弃草稿；复制短标签标明下一组，工具长文案说明覆盖已有输入。当前组始终在键盘上方；编辑时切到统一紧凑上下文。休息提示缩成单行，保留 ±10 秒/跳过；有撤销时只展示撤销，休息结束日期继续运行。
- 普通数字键 48pt，K3 数字键 44pt；字段高 48pt，主操作高 52pt，其余目标 ≥44pt。使用字段名/值、选中语义、键盘键 trait；装饰隐藏。
- 原型支持大字时的页面回退，但不能把 macOS 的字体缩放等同于 iOS；真实 Dynamic Type、VoiceOver 与 detached inputView 仍需生产迁移验收。

## 生产能力保留

源码 `VitalStride/Sources/WorkoutNumericKeyboard.swift` 的既有能力包括：左/右单侧重量、递增/递减子组、循环次数桶、复制覆盖下一组、完成收键盘、UIKit detached inputView 的 Theme 注入。本轮只演示常规重量/次数、固定次数预设、复制和记组。工具页明确列出未接入项，迁移不得删掉已有能力或将固定预设替换成未经确认的生产合同。

## 性能与评审

键盘没有图片、模糊层、网络或独立 timer；输入只更新小型草稿，不执行历史查询或持久化。休息仍由局部 TimelineView 按结束日期更新。生产输入延迟、动画帧时、能耗与 UIKit 键盘高度尚未测量，不用导出速度代替性能结论。

独立评审使用实际 18 张键盘对比板及典型状态，按原七维 /35 打分、给出 P0/P1，修 P0并解决或披露 P1。所有图是 macOS ImageRenderer 的手机尺寸图，不是 iOS Simulator 截图。
