# B 定稿细化：连续动作、snackbar 与玻璃浮层

2026-10-16 · 用户选定 B，替代 V2 中 C 的推荐。主题色继续独立，保留 DesignKit blue/slate。仅 Prototype，与生产 AppUI 隔离。

## 布局与行为合同

- **左右独立滚动**：左边 64pt 动作轨道，右边连续显示全部动作的组表。右侧进入下一个动作时，左侧高亮跟随并将该动作滚入可视范围；左侧点击跳转右侧对应动作，末尾也能顶端定位。
- **浏览与输入分开**：右侧滚动只更新浏览位置，不提交草稿、不切输入对象。左侧用蓝色标出浏览动作，用14pt铅笔与12pt“编辑”标记操作对象。底栏 / 键盘 footer 以13pt字写明编辑动作与组号并支持点按定位；常态底栏提供 44pt“定位”入口。
- **明确点击才切对象**：点另一动作侧栏或另一组时，有效草稿先保存且不记组；无效草稿阻止切换。点数字即编辑该组。More 的操作范围仍绑定明确选择的组 / 动作。
- **保留 snackbar**：休息与撤销使用独立 60pt 圆角浮层，距内容左右12pt、底部10pt；出现在主操作 / 键盘上方。撤销优先，明确显示被删动作与原组号；原休息时间继续，并在第二行显示。无提示不占固定状态行；内容尾部预留滚动余量，浮层出现不改变列表视口高度。
- **玻璃的职责**：snackbar、底部操作、键盘外壳、More 抽屉用材质建立浮层；数据表使用不透明卡面与0.5pt细边，行内不用实时玻璃。普通组行52pt、组号与完成按钮44×48pt；浮层操作至少44pt。
- **系统适配**：iOS26/macOS26+运行使用原生 `.glassEffect(.regular)`；旧系统使用 material；减少透明度时改为不透明面板。侧栏与定位动画遵从 Reduce Motion。不增加每行模糊，不跟踪每像素位移；可见目标变化只更新独立导航状态。

## 图像证据边界

`b-shots/` 是 macOS ImageRenderer 的手机尺寸导出（393 / 375×852pt，2×），使用演示数据。ImageRenderer 无法采样原生窗口背后的 Liquid Glass，因此导出分支明确使用 material＋边缘高光近似；不能据此宣称原生 Liquid Glass 光学效果已验收。

导出滚动定位图从对应 section 顶部显示相同组件，证明落点内容与输入对象的区分，不证明真实拖动同步。自动原生窗口交互因工具未授权而未执行。SwiftPM 编译确认 API 可用；状态测试检查浏览不会绑定或提交草稿。没有进行 iOS Simulator、VoiceOver、真实 Dynamic Type、触控手势或生产性能测量。
